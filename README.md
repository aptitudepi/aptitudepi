DESCRIPTION
     Devkumar Banerjee is a Computer Science student at Texas A&M
     University (Class of 2029) whose journey into computing began
     with building his first PC in 5th grade.

     He currently researches cancer radiology @ MD Anderson, graph
     neural networks @ DIVE Lab, and security @ AGGIES Lab, while
     working as an SRE intern @ Lockheed Martin. Previous work
     includes nanomedicine ML research @ Houston Methodist and
     transcriptomics platform development @ UTHSCSA.

     His profile page at https://aptitudepi.github.io is implemented
     as a browser-based terminal emulator built with xterm.js,
     Three.js, Anime.js & Motion, featuring 25+ commands, a virtual
     filesystem, ASCII art boot sequence, CRT scanline/noise overlay
     effects, and interactive Hacker News / weather / markdown
     viewers.

OPTIONS
     The following commands are available at https://aptitudepi.github.io:

     help           Display list of available commands
     cv             Display interactive resume (ASCII neofetch)
     ai, llm        Chat with local LLM (llama.cpp / Groq)
     hn             Browse Hacker News top 30 stories
     hn &lt;N&gt;         View story details with comments
     weather        Fetch weather forecast via Open-Meteo API
     md &lt;url&gt;      Render markdown from URL in fullscreen viewer
     matrix         Toggle Matrix rain animation
     crt            Toggle CRT scanline overlay effect
     noise          Toggle noise texture overlay effect
     fortune        Display random tech quote
     history        Show command history
     ping &lt;host&gt;   Ping a host
     whoami         Display current user
     vm             Boot Buildroot Linux VM in browser (v86)
     banner         Display ASCII art
